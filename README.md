###Итоговый вопрос 
- Потому что, ч/з кэш-линии данные передаются по несколько штук, сам по себе кэш самая быстрая память, и все элементы передаются последовательно, т. е. возможно понадобятся след. элементы

###Контрольные вопросы
####1. Зачем процессору нужна кэш-память?  
- Чтобы быстрее работать

####2. Чем кэш отличается от оперативной памяти?  
- Тем, что кэш ближе ко всем вычисл. блокам и работает быстрее

####3. Что такое кэш-линия?  
- Линия по которой передаётся информация

####4. Почему последовательный доступ к массиву обычно удобнее для кэша, чем доступ с большим шагом?  
- Потому что все данные передаются пачками(1,2,3,4,5,...) и процессору удобнее брать последовательно элементы, а не с шагом

####5. Почему результаты эксперимента могут немного отличаться при разных запусках?
- Погрешность, которая формируется версией ОС, обращением к данным и многим причинам

###Итоговый вывод
- Результат показал, что при запуске время выполнения программы может отличаться из-за погрешности. При отступе большего шага время выполнения меняется. кэш-память играет в этом роль, передатчика информации к процессору.
